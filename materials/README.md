# materials/ —— 素材目录（不提交）

这里存放**不会提交到 git** 的原始素材文件：下载的视频、音频、图片、转录稿、临时产物等。

## 目录约定（按类型分子目录，避免混在一起）

| 子目录 | 用途 |
|--------|------|
| `videos/` | 下载的原始视频文件 |
| `transcripts/` | 视频/音频的转录稿（json/txt 等） |
| `images/` | 图片、截图 |
| `audio/` | 音频文件 |
| `tmp/` | 其它一次性临时产物 |

> 不存在的子目录用到时再建，新增类型同样加一个小目录即可。

## 规则

- **目录与本文档会被提交**（占位用），里面的内容一律被 `.gitignore` 忽略。
- 放进来即可，不用考虑 git 状态；体积大、一次性的文件都丢这里。
- 需要长期保留的文档 / 配置请放到项目根目录或 `docs/`，不要放这里。
