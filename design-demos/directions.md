# 六张方向卡 → 挑三张做完整版

秒数轮盘：S=54 → 网页分区 `54 % 20 + 1 = 15`（实用主义彩虹分类文档）；东亚分区 `54 % 12 + 1 = 7`（节气色谱）。
外观账本：空（首次交付），无撞车约束。

---

## 候选 1 · 最佳设计师｜Dieter Rams（博朗 / Ulm 系统派）
- **借的是什么**：「少，但是更好」——一个对象只承担一个功能；界面把导航与内容严格分层，控制项按使用频率决定 prominence。一句不带外观的机制：*导航只在需要时占地方，内容永远占主位；同类控件全站只有一种长相*。
- **不借的、自己长的**：不拿博朗的米白+红开关；颜色从品牌靛蓝 `#5B63D3` 与近黑表面推导，圆点母题来自 elsewhen 轨道。
- **主角素材**：真实 logo + 轨道圆点做成「航向刻度」；无摄影图。
- **骨架**：顶部细标题栏 → 左侧 200px 常驻导航（含 3 目标小卡）→ 中间单栏工作区 → 右侧按需展开的审阅抽屉。
- **胆量花在哪**：把「最多 3 个目标」做成侧栏顶部固定刻度区，六个导航项退到其下。
- **form 来自内容的哪里**：3 个目标 = 3 个刻痕；偏移圆点标记「当前偏离的那一个」。

## 候选 2 · 最佳设计师｜原研哉（白 / 空寂 × 瑞士网格混血，见 web#20）
- **借的是什么**：UI 退到背景，内容成为唯一有颜色的东西；留白是构图不是缺席。机制：*把界面 chrome 压到最低对比，只让内容本身有重量*。
- **不借的、自己长的**：不做日式白盒画廊的空；这里是工具，得有密集信息，留白只用在标题与状态区。
- **主角素材**：字标 + 大量真实文字内容。
- **骨架**：近白单栏长卷，极窄左 rail，状态以细小字重呈现。
- **胆量花在哪**：主区几乎无边框无卡片，靠排版层级撑住。
- **form 来自内容的哪里**：「记录此刻」——一页就是一段时间。
- **备选理由**：与候 selected 3/5 气质过近（都偏安静克制），且对密集知识页风险高。

## 候选 3 · 现实参照｜Linear 2026「A calmer interface for a product in motion」
- **核实与参考板**：`https://linear.app/now/behind-the-latest-design-refresh`（2026-03-12，已 WebSearch 核实），截图 `refs/linear.png`。
- **借的是什么**（`ref_card.py measure` 因缺 Python Playwright 未跑，以下为截图肉眼读数，标为观察值）：*导航 sidebar 调到「a few notches dimmer」，到站后主动退居背景；分隔线减少并软化，「structure should be felt not seen」；tab 收窄不横跨全宽*。只借这一条机制：**chrome 的视觉权重随「是否已到达」变化**。
- **不借的、自己长的**：不拿 Linear 的蓝紫渐变、issue 状态语义、快捷键文化；颜色从 elsewhen 品牌靛蓝重长。
- **主角素材**：产品界面本身（对话流）+ 真实字标。
- **骨架**：极窄左 rail（56px）+ 中间宽工作区 + 右侧「上下文条」常驻但低对比。
- **胆量花在哪**：整个左侧导航用低对比灰，只有当前项与未读点有颜色。
- **form 来自内容的哪里**：「AI 零打扰」——提醒横幅全部收进低对比的右侧上下文条。

## 候选 4 · 现实参照｜Craft（craft.do，桌面文档应用）
- **核实与参考板**：`https://www.craft.do/`（已 WebSearch 核实，Apple 2021 Mac App of the Year），截图 `refs/craft.png`。
- **借的是什么**：*侧栏直接贴在窗口表面而不是浮起来的卡片；中心文档是唯一主角，界面从文档取一点颜色*。只借这一条：**容器退隐，内容取色**。
- **不借的、自己长的**：不拿云朵插画、彩色卡片网格、macOS 玻璃高光。
- **主角素材**：文档/知识页正文。
- **骨架**：左侧栏贴边 + 中心单栏阅读 + 右侧 TOC。
- **胆量花在哪**：全界面无卡片阴影，靠留白与细线分区。
- **form 来自内容的哪里**：知识页是「被反复读的稿子」。
- **备选理由**：与候选 2 的安静单栏过近，且与候选 5 的三栏骨架重叠。

## 候选 5 · 秒数轮盘｜网页 #15 实用主义彩虹分类文档（Tailwind Docs）
- **核实**：`references/design-styles.md:182-188`，样张 `web/15-utility-colorful-docs.jpg`。
- **借的是什么**：*左 taxonomy + 中正文 + 右 TOC 三栏；用功能色相条给分类编码，蓝色只做品牌、其余色只做类别*。只借这一条：**颜色按功能分工，一类一相**。
- **不借的、自己长的**：不拿 Tailwind 天蓝品牌色、代码块语法色、开发者文档语气；色相从 elsewhen 靛蓝出发做受控扩展。
- **主角素材**：知识页 + 「证据堆叠」数据图（同一事实被 N 条记录支持）。
- **骨架**：左 240px 分类树（7 色点）→ 中知识正文 → 右证据 / 目录栏。
- **胆量花在哪**：把 7 类知识色点从 Tokyo Night 换成一套有语义顺序的统一色相环。
- **form 来自内容的哪里**：「知识复利」= 证据堆叠，条数就是可信度。

## 候选 6 · 秒数轮盘｜东亚 #7 中国传统色·节气色谱
- **核实**：`references/design-styles.md:744-750`，样张 `east/07-traditional-colors-solar-terms.jpg`。
- **借的是什么**：*把时间做成导航——24 条竖色条横贯底部，当前节气那条升高变宽成为全页强调色*。只借这一条：**当前时刻用「升高/变宽」而非用颜色以外的方式标记**。
- **不借的、自己长的**：不拿节气名、传统色名、暖纸底、宋体。
- **主角素材**：底部时间刻度条。
- **骨架**：顶部内容 + 底部时间轴条。
- **胆量花在哪**：底部时间轴贯穿全 App。
- **form 来自内容的哪里**：「记录此刻」——此刻就是那条升起的刻度。
- **备选理由**：套在桌面工具上容易用力过头（去掉时间轴信息不糊，说明是装饰），只留作备选。

## 挑中的三张（Phase 4 标准：单看够好 / 彼此不一样 / 不撞账本 / 不用力过头）
1. **候选 1 → dir-1**：航向刻度侧栏。骨架 = 侧栏目标刻度 + 中工作区 + 右抽屉；气质 = 系统、克制。
2. **候选 3 → dir-2**：退隐导航。骨架 = 极窄 rail + 宽工作区 + 低对比上下文条；气质 = 安静、线性。
3. **候选 5 → dir-3**：复利图谱。骨架 = 三栏分类树 + 正文 + 证据栏；气质 = 信息密度、有序。

三张骨架互不相同（目标刻度 / rail+上下文 / 三栏）；外观家族分别是深底靛蓝 / 暖中性深灰 / 浅色分类色，不挤在同一家族；都没有把整页做成道具。

## 没做的三个备选（展示时一并告知用户）
- 候选 2（原研哉白盒）：与 dir-2 的安静气质过近，知识页密集时留白难成立。
- 候选 4（Craft）：与 dir-2/3 骨架重叠。
- 候选 6（节气色谱）：时间轴做桌面工具主导航有「为隐喻而隐喻」的风险；若用户看中，可做成完整版。
