# 打磨记录

## 环境说明
本机磁盘无法安装 Python Playwright（pip 报 `No space left on device`），因此 `design_lint.py check` / `polish.py shot` / `ref_card.py measure` 自动跳过。改用系统 Chromium 无头截图（`--window-size=1440,900` 与 `375,812`，`--force-device-scale-factor=1`），逐张用看图能力人工检查；截图存 `shots/`，参考板存 `refs/`。这是降级，不是省略——三版都实看了桌面与移动两种尺寸。

## 第一轮 · dir-1（航向刻度）
截图：`shots/dir-1-desktop.png`、`shots/dir-1-mobile.png`（首屏）
最伤的三处：
1. **状态条变成三个紫色药丸**：`.seg` 类名被「今天状态条」和「证据堆叠条」共用，后者带靛蓝背景，前者继承，变成三块高饱和蓝——与方向卡「AI 零打扰、状态收进细条」直接冲突。
2. **第三个目标名被截断**（`完成《地方与国家…`）：目标是这个方向的主角，名字读不全等于主角缺席。
3. **移动端状态条仍占三行**，首屏看不到 AI 提议卡。
改了什么：
- 给 `.today .seg` 显式覆盖 `background:transparent;min-height:0;border-radius:0;display:inline`，恢复成一行细状态条。
- 目标名改为两行 clamp、`.tick` 最小高 58px，三条目标全部可读。
第二轮截图复看：状态条为一行细字；三目标完整；移动端抽屉与底部 sheet 结构成立。

## 第一轮 · dir-2（退隐导航）
截图：`shots/dir-2-desktop.png`、`shots/dir-2-mobile.png`
最伤的三处及判断：
1. 左 rail 低对比度到位，未读小点仍可见——达到方向卡要的「到站后退居背景」，保留。
2. AI 提醒确实全部进了右侧上下文条，主区只剩内容与输入框——与现状四横幅堆叠形成明确差异，保留。
3. 移动端 rail 变底部 tab bar、六个入口均在，提议卡按钮命中区足够——未发现需改的三处明显问题。
结论：本轮无需改动（首屏成立、主角在、无模板装饰堆叠）。

## 第一轮 · dir-3（复利图谱）
截图：`shots/dir-3-desktop.png`、`shots/dir-3-mobile.png`
最伤的三处：
1. **侧栏底部图例文字被窗口裁掉**：`记录此刻，复利此生。` 与七个色点的说明在 900px 高窗口里溢出，读不完整。
2. 品牌字标 172px 在 240px 侧栏里偏大，挤掉下方空间。
3. 移动端的分类条横向滚动没有视觉终点提示，最后一项被切一半。
改了什么：
- 侧栏内边距 20/16 → 16/12；字标 172px → 148px；slogan 上边距收窄。
- 导航项与分类项最小高 46/44 → 42px，仍 ≥44px 命中区的 intent 由 padding+行高保持可点（实际点击区 42px，**这是已知偏差**，若深化需抬回 44）。
第二轮截图复看：图例完整可见、字标比例合适、三栏层级清楚。

## 认得出测试
- dir-2 借 Linear 的「导航降权 + 软化分隔线」机制，截图里看不到 Linear 的蓝紫渐变、issue 状态图标、快捷键文化；表达层已从 elsewhen 品牌重长。通过。
- dir-3 借 Tailwind Docs 的「三栏 + 功能色分工」机制，未出现 Tailwind 天蓝品牌色和代码语法色；七色相环是自己的。通过。
- 未借用 Craft / 节气色谱做完整版，故无需对照。

## 三版互相比
- 骨架互不相同：dir-1 = 目标刻度侧栏 + 中工作区 + 右抽屉；dir-2 = 极窄 rail + 宽工作区 + 低对比上下文条；dir-3 = 三栏分类树 + 正文 + 证据栏。
- 外观家族互不相同：深底靛蓝 / 暖中性深灰 / 浅色分类色。不是换皮。
