# 品牌资产规格 · Elsewhen / 别时

来源：`assets/brand/README.md`、`assets/brand/elsewhen-logo-v2.svg`、`assets/brand/elsewhen-icon-v2.svg`（项目内真实资产，已核验）

## 品牌事实
- 英文名标：**Elsewhen**；中文名：**别时**。
- 释义：else（别的）+ when（时刻），「在别的某个时刻」。
- Slogan：**记录此刻，复利此生。**
- 视觉母题：**开口的时间轨道 + 偏移的「else」圆点**——一个不在此刻的瞬间。
- 色板（品牌资产）：深蓝 `#171A21` → 靛蓝 `#5B63D3`（轨道渐变）；图标底 `#16171C`–`#23252C`。
- Logo SVG 里的实际渐变停靠：`#3E4453` → `#5A60D8` → `#7B81F0`；圆点 `#6A6FE0`，光晕 `#7B81F0`。
- 字体：Inter（字标），几何无衬线。

## 轨道几何（所有图标共用，不要改比例）
- `r=196`、`stroke=44`、圆点 `r=28`、光晕 `r=62`。
- 只有容器与导出尺寸按平台调整。

## 三方向如何使用
- **三个方向共用同一套真实 logo / 字标 / 轨道几何**，差异在界面诠释，不重画品牌。
- 品牌色是「可借」的资产；界面色板可以从题材里推导，但不能假装品牌另有主色。
- 现状 UI 默认强调色为暖橙 `#E9A568`（`app_theme.dart`），与品牌靛蓝不一致——这是诊断项，三方向需各自给出处理：
  - 方向一：向品牌靛蓝收敛，暖橙只留给「此刻/进行中」语义。
  - 方向二：保留四套 flex 预设的可换色能力，但把「偏移圆点」作为不随主题变的签名。
  - 方向三：以靛蓝为系统色，7 类知识色相作为受控的数据色，二者分工明确。

## 不做的
- 不重画 logo、不换字标字体、不新增品牌吉祥物。
- 不用 emoji 当图标。
