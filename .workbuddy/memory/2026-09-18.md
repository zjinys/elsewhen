## Linux 任务栏图标修复（KDE Wayland）
- 关键：GTK `gtk_window_set_icon`（`_NET_WM_ICON`）在 Wayland 下被忽略；KDE/GNOME 的 Wayland 任务栏图标 = 窗口 app_id → 匹配的 `.desktop` 文件 → `Icon=` → 图标主题。
- 修复：`ui/linux/CMakeLists.txt` 的 `APPLICATION_ID` 从 `dev.elsewhen.elsewhen_ui` 改为 `io.github.elsewhen.Elsewhen`（与 `.desktop` 文件名 / `StartupWMClass` / hicolor 图标名一致）；GTK runner 内嵌 v2 PNG 设置 `_NET_WM_ICON`（X11 会话仍生效）。
- 需执行 `./scripts/install-linux-desktop.sh`（`make install-desktop`）把 `.desktop` + hicolor 图标安装到 `~/.local/share`，否则 Wayland 解析不到图标。
- 验证：XWayland 下 `xprop` 确认 WM_CLASS=io.github.elsewhen.Elsewhen、`_NET_WM_ICON` 存在。
- 遗留：`.desktop` 的 `Exec=elsewhen capture` 指向 Rust iced 捕获窗（非 Flutter 主窗），打包未包含 elsewhen_ui，是既有打包设计，未改动。
