# DMCA 投诉处理政策（模板）

> 服务运营商填写方括号内容后，发布到对外站点（如 `elsewhen.example/DMCA`），
> 并保证其中信息与版权局登记的 Designated Agent 完全一致。
> 登记流程见文末「登记操作指南」。法务定稿请找执业律师复核。

---

## 1. 服务说明

[服务名称]（以下简称“本服务”）是一款本地优先的端到端加密（E2EE）个人记录应用。

- 用户数据的**加解密完全发生在用户设备上**。本服务的同步中继服务器
  （relay）只转发以密钥 AEAD 封装的密文信封；
- 运营者**没有能力阅读、索引或识别**任何用户内容的主题、作者或权利归属，
  因此也无法主动监测侵权内容（17 U.S.C. §512(a) mere conduit 位置）；
- 本服务不提供公开内容分发、搜索或目录功能，不向第三方公开用户数据。

## 3. 侵权通知（Takedown Notice）

合格的通知应包含 17 U.S.C. §512(c)(3) 要求的全部要件：

1. 被投诉作品的权利人 / 独家授权人的签名（电子签名有效）；
2. 被投诉作品的描述与识别信息；
3. 权利人认定侵权的充分理由（如有条件需提供比对证据）；
4. 投诉人的联系方式；
5. **善意声明**：对材料的使用未经权利人、其代理人或法律授权；
6. **如实声明**：通知所述属实，且投诉人是权利人或有权替其行事（伪证承担责任）。

发送至第 2 节邮箱。**警示**：故意虚假投诉可能承担 §512(f) 下的损害赔偿责任。

## 4. 受理与响应

- 运营者在收到通知后 [X 个工作日] 内给出响应；
- 由于本服务无法读取密文，运营者针对密文内容的典型处置是：
  依据运营者独立条款（禁止在快照/同步数据中从事侵权分发）对该
  **中继通道/信箱**采取暂停、复审或终止服务，并要求用户提供澄清；
- 若投诉针对公开可见的素材（如官方文档、宣传页），运营者可直接移除；
- 将依据 §512(g) 的反通知（counter notice）与恢复程序处理受影响用户的申辩。

## 5. 重复侵权者政策（Repeat Infringers），§512(i)

被确认在合理知情下多次转用服务从事侵权行为的账号/设备配对关系，将予以终止。

## 6. 登记操作指南（对内职责，发布前可删除本节）

- 登记地址：https://dmca.copyright.gov —— 网页流程：注册账号 →
  Add Service Provider → 填运营主体（真实街道地址）→ 备用名（含应用名
  `elsewhen` 与发布域名）→ 填代理 → 核对 → 认证并付款（Pay.gov，每次 $6）。
- **每 36 个月必须续展**（amend 或原样 resubmit，每次 $6）；系统会在
  90/60/30/7 天前发邮件提醒——保留登记邮箱可用。
- 运营主体名称、地址、代理任一变化都必须立即 amend，否则 safe harbor 失效。
- 2016 年后不再接受纸质登记，一律线上。
