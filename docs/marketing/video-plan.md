# Elsewhen 宣传视频规划

> 四条产品线：品牌旗舰（1 支定调）→ 功能短片（立卖点）→ AI Agent 科普（引流量）→ 开发者向（转化）。
> 每周 1–2 支节奏，旗舰片先行。

## 红线（每支都要遵守）

- **演示环境用沙盒**：`ELSEWHEN_DATA_DIR=/tmp/elsewhen-demo` + 预埋生活化假数据（健身/读书/项目 5–6 条），真实数据、真实 API Key、真实知识页绝不能入镜
- 录屏统一浅色主题、OBS 60fps、鼠标高亮、全程字幕（短视频 80% 静音观看）
- 收尾统一：slogan"记录此刻，复利此生" + GitHub 链接
- 展示密钥字段一律打码或使用明显假 key（`sk-demo-xxxx`）

## 产品线 C：AI Agent 科普系列（60–90s，引流主力）

公式：**生活化钩子 → 讲清一个概念 → "Elsewhen 就是这么做的"软收尾**。
 科普选题全部对应 Elsewhen 的真实机制，讲完不虚。

| # | 标题（钩子向） | 科普概念 | 对应机制（收尾落点） |
|---|---|---|---|
| C1 | 为什么 AI 聊完就忘？ | 上下文窗口是易失记忆；会话结束即遗忘，长对话还会稀释注意力 | 事件库 = 外置持久记忆，原始事件永不被覆盖 |
| C2 | RAG 在检索，不是记忆 | 向量召回每次"重新推理"，答案漂移、无法复利 | LLM Wiki"编译一次，持续更新"：先沉淀成页面，再增 correcting 增量更新 |
| C3 | AI Agent 到底是什么 | 感知→决策→行动的循环 + 工具调用；不是聊天机器人 | 后台 worker：保存→登记任务→分析→消化→审阅，全自动自律循环 |
| C4 | AI 会胡说，谁来兜底？ | 幻觉与 human-in-the-loop：让 AI 提议，程序校验，人拍板 | 审阅卡 + Rust 核心确定性合并，evidence_count AI 改不了 |
| C5 | 为什么要用你自己的 API Key | 云端账号 = 你的数据过别人服务器；本地密钥 = 只有你能解密 | AEAD 密封密钥只在你的机器上，同步内容不含明文 Key |
| C6 | 怎么"驯服"一个 AI 员工 | 用 schema/规则约束输出：AI 是守纪律的维护者，不是自由的诗人 | schema + Rust 合并规则双层约束（参考 Karpathy LLM Wiki） |
| C7 | 端到端加密到底是什么 | 中继瞎转发：它只见密文，配对双方才持有钥匙 | 盲中继同步架构， Service 端读不到明文 |
| C8 | AI 失败了为什么不用慌 | 指数退避重试：网络抖动是常态，工程上让失败变等待 | 分析/消化失败自动退避，连续失败冷却 6 小时后自愈 |

B 站/YouTube 版可把 C 系列合并成 8–15 分钟合集：《一文看懂 AI Agent 的记忆、幻觉与审阅——以及你的笔记应用该怎么做》。
