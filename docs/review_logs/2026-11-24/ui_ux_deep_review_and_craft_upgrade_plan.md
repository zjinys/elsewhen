## 一、现状诊断与核心痛点

| 序号 | 痛点现象 | 代码定位 / 现实表现 | 体验后果与与产品理念的冲突 |
| :--- | :--- | :--- | :--- |
| **1** | **核心主角错位** | `sidebar_destinations.dart`<br>`goal_view.dart` | 产品最大的差异化灵魂是**“同时最多 3 个核心目标”**，但在 UI 中它与对话、知识、情报、回顾、同步并列平铺在侧栏。在日常最频繁的对话流中，**核心目标完全隐形**，用户感知不到自己航向的引导。 |
| **2** | **主区上方横幅“堆叠轰炸”** | `message_area.dart:301-330` | 主流上方纵向堆叠了：`_NowStatus`（今天状态与快捷按钮）+ `ReminderBanner` + `GoalCompassNudgeBanner` + `_PendingMemoryBanner` + `_PendingRelationsBanner` + `SearchBar`。极端情况下占满半屏，**与“AI 日常零打扰、3~5天偏离才递一面镜子”的承诺严重冲突**。 |
| **3** | **视觉色彩体系失控与脱节** | `app_theme.dart` vs `sidebar_wiki_tab.dart` | ① 品牌资产（`assets/brand/`）是深墨 + 靛蓝（`#5B63D3`，时间轨道母题），而现有主题默认界面强调色偏向暖橙（`#E9A568`）；<br>② 知识库的 7 类实体直接硬编码了 Tokyo Night 色板，回顾页又出现第三套红绿，缺乏全局统一的**数据语义色彩系统**。 |
| **4** | **弹窗依赖重（Dialog-heavy）** | 约 70 处 `showDialog`<br>`main_screen.dart:65-73` | 速览目标、查看待办、记忆详情、标签录入多采用模态弹窗，严重打断单手或键盘沉浸心流。同时桌面小窗（<1024px）直接暴力降级为手机抽屉，界面在双栏与抽屉之间跳跃。 |
| **5** | **“知识复利”缺乏直观可视化** | `wiki_page_parts/` | “同一事实被越多记录支持越可信”停留在概念层，知识页更像普通的 Markdown 笔记，缺乏**证据堆叠（Evidence Stack）、引用密度、时间回溯条**的可视化呈现。 |

## 二、设计哲学与视觉语言重构

### 1. 材质与分层光影（Materiality & Layered Surfaces）
现有 UI 存在纯黑底色与粗硬边框带来的生硬感。质感应用的核心在于**“材质深度”与“分层环境光”**：
- **墨黑画布分层（Depth Levels）**：
  - `Canvas`（底层基底）：`#07090E`（深空墨黑，微偏冷靛，非死黑 `#000000`）。
  - `Surface-1`（侧栏/工具栏）：`#0D1117`（微明度提升，形成空间沉浸底）。
  - `Surface-2`（主内容卡片）：`#131823`（轻量提升，搭配 0.5px 发光发丝线）。
  - `Surface-3`（悬浮面板/胶囊/浮层）：`#1A2130`，配合 `BackdropFilter` 磨砂毛玻璃。
- **发丝细边框（Hairline Borders）**：
  - 彻底摒弃粗重的一体边框，全站采用物理 1px（高分屏 0.5px）半透明复合描边：
    `Border.all(color: Colors.white.withValues(alpha: 0.08), width: 0.5)`，在深底上形成极度高级的微光切边（Edge Highlight）。
- **复合柔影（Multi-layered Micro-shadows）**：
  - 弃用单层生硬模糊阴影，改用双层柔影（接触微影 + 环境柔散光），让卡片有“浮在微光表面上”的悬浮感。

### 2. 品牌色彩系统收敛（The Elsewhen Indigo & Functional Hues）
- **核心品牌签名色**：
  回归品牌母题的**静谧靛蓝（`#5B63D3` ~ `#6A6FE0`）**与**开口轨道**，作为全局唯一的 Primary Accent（用于焦点、主操作、激活态）。
- **语义告警与偏离（The Else Dot）**：
  品牌的“偏移圆点”母题作为核心反馈，暖橙/琥珀（`#F59E0B`）仅用作目标偏离设问与等待确认；薄荷绿（`#10B981`）用于完成与落库；深红（`#EF4444`）用于破坏性操作。
- **7 类知识色谱低饱和化**：
  将原本刺眼的 Tokyo Night 纯色点，重构为一套优雅的**低饱和度墨水色相**，融入卡片标签，不再抢夺阅读视线。

### 3. 排版节奏与字体质感（Typography & Rhythm）
- **字体族阶梯**：西文与数字采用 **Inter**（具备优秀的 Tabular Figures 数字等宽对齐特性），中文排版使用系统顶级苹方 / 思源黑体，阅读态支持衬线模式切换。
- **微文字体系（Micro-typography）**：
  - 状态、徽标、时间戳等辅助信息严格采用 `11px ~ 12px`，搭配 `letter-spacing: 0.2px` 与中灰 `textTertiary`，形成极为典雅的信息排布。
  - 正文保证 `14px / 1.6` 行高（桌面）与 `15px / 1.55` 行高（移动端），留足呼吸间距。

## 四、核心工作区逐项打磨方案

### 4.1 对话与记录主流：消灭横幅轰炸，引入「静默状态微胶囊」
- **现状改造**：
  移除 `message_area.dart` 中垂直平铺的 5 个 Banner。
- **优化方案**：
  在输入区上方或顶栏折叠为一个**自适应「状态胶囊行（Context Status Capsule）」**：
  - 默认态只占一行（高 32px）：显示 `[今日记录 8 条 · 3 个目标运行中]`，右侧微提示 `[1 项待确认记忆 · 1 条航向镜子 ›]`。
  - 点击或快捷键平滑滑出**「随伴抽屉 / 上下文折叠卡片」**，将记忆确认、目标偏离设问（Compass Nudge）、待定关系集中处理。
  - 主区首屏永远留给最新对话，恢复“AI 零打扰”的产品体验。

### 4.2 目标与航向罗盘：3 核心目标常驻刻度仪表
- **侧栏置顶小卡**：
  在左侧栏最上方保留 `1 / 2 / 3` 三张紧凑卡片（或刻度点），展示目标简称、当前阶段抓手、以及未动天数。
- **偏离状态反馈**：
  当某个目标偏离超过 3 天，目标刻度旁仅点亮一颗小小的**偏移圆点（正是品牌的“else”圆点母题）**，悬停或轻触时浮现 AI 设问，克制且优雅。

### 4.3 知识库：让“知识复利与证据链”看得见
- 每一篇被 AI 提炼出的知识页，页首展现**“认知来源热度与时间线”**。
- 正文中观点引用旁边附带低调的数字微角标，点击侧滑出原始日记锚点，实现**真正可信、可追溯的知识资产感**。

### 4.4 商机情报 (Scout) 与回顾 (Review) 终端质感
- **Scout 商机与动态**：采用研究终端的高密度卡槽布局，来源标签、可信度评分与核心摘要层次分明。
- **回顾长卷**：时光轴刻度线形式，将足迹、目标推进比、知识新增量以精致的数据微图（Sparklines）呈现。

## 五、微交互与触感反馈体系

1. **触觉回弹与阻尼（Scale & Feedback）**：
   所有的按钮、卡片、胶囊在按下（Press）时加入极轻微的物理收缩反馈（`transform: scale(0.98)`，120ms easeOutCubic）。
2. **渐进展开动效（Smooth Layout Transitions）**：
   折叠面板、抽屉弹出严格遵循 `200ms ~ 240ms Curves.easeOutQuart`，消除任何硬切（Jank）和掉帧。
3. **状态切换平滑淡入（Cross-fade on State Switching）**：
   导航切换、会话切换时，内容区采用微位移淡入（Slide + Fade，偏移仅 4px），给用户一种“内容就在手边”的轻盈感。

## 六、分阶段落地实施路径

- **Phase 1：设计系统基石**：重构 `app_theme.dart` 与 `design_tokens.dart`，确立深空墨黑基底、品牌靛蓝主色、0.5px 发丝切边与多层微阴影。
- **Phase 2：对话主区降噪**：落地单行「静默状态胶囊」，折叠消除 5 层堆叠横幅，打磨悬浮胶囊输入条的聚焦与微动效。
- **Phase 3：骨架与航向重塑**：将 3 个核心目标重构为左侧栏顶部的“常驻刻度仪表盘”，优化标题栏与全局 Command Bar。
- **Phase 4：知识复利与细节**：知识库落地“证据链可视化”微组件，打磨按钮按压缩放、抽屉展开等微交互。
