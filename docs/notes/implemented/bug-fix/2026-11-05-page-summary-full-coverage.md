# Agent Note: 页内自然语言总结覆盖全文

Status: implemented

## Problem

页内聊天默认保存 local_question。菜单操作会切换 full_summary，手动输入“总结这篇文章”却仍只拿局部片段。读取工具的限长片段不能替代整篇总结。已有全文管线对长 imported 页面强依赖后台阅读缓存，刚导入的文章可能无法立即总结。

## Decision

页面材料装配识别自然语言总结请求，将单页局部问答的本轮读取范围提升为 full_summary，复用既有连续分块归纳。明确局部请求或已选区默认保留局部；明确要求全文时可扩大到整页。任务的材料版本保持原基线，不改写已保存的任务，不授予编辑权限。

长导入页优先复用与当前原文匹配的完整阅读缓存；缓存未就绪或没有匹配快照时，使用本轮可取消的全文分块读取，不等待后台、不注入开头片段冒充全文。全量片段限制、空响应/截断校验、页面版本校验与最终请求预算仍适用。

## Alternatives considered

- 增大 get_wiki_page 固定截取长度：仍然会在更长文章上遗漏尾部，且扩大普通查阅的上下文负担。
- 所有页内问题都发送全文：局部问题也增加模型调用，违背明确选区，且让窗口预算随文章长度增长。
- 仅要求用户切换任务菜单或等待后台：不能满足直接输入总结请求和新导入资料立即阅读的需求。

## Verification

- `cargo test --lib ai::page_tasks::tests`：22 passed，含新增 5 项回归。覆盖自然语言与否定表达、显式选区、既有编辑/对照任务隔离、7000 多字首尾连续覆盖、导入页无缓存前台阅读与完整缓存复用、途中截断和 32 段上限。
- `cargo test --lib ai::conversation::tests::protocol_tests`：17 passed。新增真实 provider 装配与回环 HTTP 回归分别走持久任务和旧式输入入口：原任务为 local_question，三次有界阅读的 user 原文拼回恰好等于 7000 多字全文，第四次最终回答请求包含三段归纳和尾部限制，保留非逐字原文标记，原文及已保存任务均不改变。
- 模拟服务只处理合成资料，不调用真实付费模型；覆盖验证不等同于真实模型总结质量验收。前一项目录修复的全量测试结果不冒充本次全量复验。

## Consequences

整篇总结使用全部连续片段的归纳，主回答看到的仍是明确标记的 AI 归纳而非逐字原文。首次阅读无缓存长文增加分块模型调用；任一片段失败均不声明完成。超过本轮 32 段上限仍明确拒绝而不偷偷截断。精确引文与原始证据验证保持原有契约。
