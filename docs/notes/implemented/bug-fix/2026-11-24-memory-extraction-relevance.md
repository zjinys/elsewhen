# Agent Note: 记忆提取区分长期信息与当次请求

Status: implemented

## Problem

规则将“我希望”前缀直接转换为 procedural preference，导致“希望是一系列，不是单独一个”和“结合当前知识库给出建议”等局部任务要求进入记忆。真实用户原文并不等于值得长期保存的信息。

## Decision

取消“我希望”的词法直接提取。模型提取要求正文能脱离当前对话理解，并对未来无关对话有用；具体稳定偏好、个人事实、长期限制及持续项目可以保留，当次任务要求、泛泛请求和未解析指代应返回空候选。规则及模型结果同时过滤明显的对话局部表达；原文引用真实仍不足以绕过该过滤。

## Alternatives considered

没有把所有“我希望”替换成“用户偏好”，也不向模型补写“长期/总是”来制造稳定性。没有根据截图批量删除既有记录，避免覆盖人工确认。该过滤是保守闸门，不宣称词表能够准确判断所有语义。

## Consequences

减少无价值候选，但部分隐含稳定偏好需要模型判断，宁可不保存。现存条目仍由用户编辑或删除；本次只改变后续自动提取。回归覆盖截图原句、局部写作任务、未解析指代，以及具体偏好和持续项目的保留。
