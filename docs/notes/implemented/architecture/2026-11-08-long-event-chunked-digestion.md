# Agent Note: 超长事件的持久分块消化

Status: implemented

2026-11-09 实现，分支 `feat/long-event-digestion`；范围与完整证据见[实施路线](../../../roadmap/2026-11-09-long-event-digestion-roadmap.md)和[真实模型验收](../../../testing/2026-11-09-long-event-real-model-acceptance.md)。

## Problem

[知识消化预算修复](../bug-fix/2026-11-08-digest-context-budget.md)已按实际 Provider 完整请求预算缩批次和选择相关资料，故障切换也会重新准备。尚存独立缺口：单条完整事件与固定指令本身就超过窗口时，无法再通过缩批次解决。

原直接路径在完整单事件超窗时只能保留原文并退避。本实现补齐事件级[存储](2026-11-09-event-reading-storage.md)、[预算阅读](2026-11-09-event-reading-budget.md)、[合并与最终事务](2026-11-09-event-reading-finalization.md)及[自动调度与进度](2026-11-09-event-reading-worker.md)。

## Decision

使用按事件身份持久化的分块阅读及合并流程，先把完整原文读完，再构造最终消化输入。单条事件超过预算才进入此路径，普通事件沿用已实现的直接消化；不增加手动后台触发按钮。

- 分块依据具体 Provider 的序列化输入、计数器、窗口、输出预留和安全余量决定；每块记录原事件 ID、内容指纹与明确范围，保持全文覆盖，不能只取首段。
- 原始事件仍为不可变事实源。中间摘要是带覆盖范围的生成材料，不能冒充原文；需要引用时保留可校验的原文范围及引文，不生成假的独立来源事件。
- 分块、合并和最终请求固定任务 bundle、语言策略与处理版本。缓存身份包含事件内容指纹、处理策略与模板依赖，不能跨版本或语言串用；已有运行设置变化不影响当前任务。
- 每个后台 tick 有明确的模型调用数、处理量和时间上限；中间进度持久化，重启/重试从已确认节点继续，失败不丢失之前已完成阅读。具体表结构、分块/合并上限及任务状态固定在上述实施记录。
- 任意 Provider 切换均重新预检本节点输入；节点范围变更时不得伪造原节点已读。若固定指令本身已超过全部候选 Provider 的可用输入预算，明确区分配置问题，不能无限切分空材料。
- 只有全部范围覆盖、合并完整且最终提议验证通过，才将本事件确认为消化完成；页面写入、来源证据与任务确认继续原子提交、去重并保护人工正文。
- 延续 owner/processor、租约和代数约束，旧 owner 的延迟结果不得提交；不把本机完整 Prompt/bundle 当成跨设备业务数据同步。

现有[长来源阅读](../../../llm-wiki-implementation-flow.md)及对话摘要已有分块/合并机制，本实现保留事件级独立身份与事务边界；本实现没有把来源快照或对话消息伪装成事件。长事件分析 worker 属于另一个调用路径，本项验收不据此宣称该路径也已覆盖。

## Alternatives considered

- 增大默认窗口、降低输出预留或低估 token：不能保证代理真实窗口，也无法处理任意增长的事件。
- 继续截取前若干字符后标记成功：丢失尾部事实，却把整个事件当成已读证据，不接受。
- 在一次 tick 内递归读完全部分块：大事件可能产生大量付费调用，无法满足有界调度与中断恢复。
- 要求用户手动拆成多条事件：改变原始事实身份并增加操作负担，可作为临时手段但不替代自动流程。
- 只在内存保存块结果：重启后重复计费，无法证明完整覆盖与缓存依赖一致性。

## Validation

- [x] 单条超窗事件能跨多个有界 tick 自动读完并完成消化，首/中/尾事实均有确定性覆盖验证；原始事件内容和身份保持不变。
- [x] 中途失败、重启、切换 Provider 和设置变更均保持正确范围、已确认进度及固定 bundle；不将同一节点重复计入成功进度。
- [x] 每次实际请求都通过完整序列化预算检查，覆盖小窗口、输出预留变化、中文/英文/代码及长引文；固定指令自身超窗有明确退出原因。
- [x] 中间节点失败或覆盖不全时，不发布“已完整消化”、不确认整个事件；最终验证失败无部分页面写入，重试不重复累加证据。
- [x] owner/processor 移交、租约过期和迟到结果不会越权提交；缓存不同策略/语言不串用，人工编辑保护仍成立。
- [x] 提供隔离存储/请求/Bridge 回归及真实模型长事件验证记录；模型质量与自动化证据分别报告，更新 backlog 与修复记录。

## Consequences

完整阅读增加调用数和本地缓存，使用节点数、合并深度和每任务缓存上限约束成本；当前没有跨任务全局缓存清理。分层摘要可能丢失否定、时序或尾部细节，必须保留范围与原文证据，不能仅凭“摘要生成成功”证明质量。极小窗口或超长自定义固定指令可能没有可行请求，应明确停止当前无效尝试，不声称分块能消除全部预算失败。
