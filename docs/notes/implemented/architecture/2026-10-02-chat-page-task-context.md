# Agent Note: 知识页对话的显式材料范围

Status: implemented

## Problem

此前所有页内问题均注入整页正文，没有绑定用户看到的页面版本和选区。短问题浪费预算，长文可能在最终预算边界被拒绝，修改期间还可能将旧显示内容默认为新版本。

## Decision

对应[对话路线 C07](../../../roadmap/2026-09-30-ai-chat-experience-roadmap.md)。每个输入绑定任务类型、页面身份、显示时的 authoring revision basis，以及可选字符选区。保存这些元数据与用户消息同事务，重复请求复用输入身份，不写个人事件。

局部问答与局部编辑提供带明确 Unicode 字符范围的原文；局部编辑的工具结果只作为选区替换文本，由 Rust 拼接未选中的原文。全文总结复用既有 source-reading 完整阅读根节点，未就绪时明确说明缺少覆盖，不另建来源缓存。非原料页没有 snapshot 身份，因此仅在当前任务内连续分块归纳，不伪造来源缓存；全页修订逐段产出、检查片段编号和完整性，全部通过后才建立一个待审提议。每块 3000 字、最多 32 块，超限明确拒绝，不静默截断。用户看见的材料版本只能由明确刷新替换，旧稿确认继续通过 authoring/review 规则，并重新核验所有对照材料。

## 分块语义边界

2026-10-03 真实全文验收暴露出仅检查首中尾标记不足：固定3000字符切块把“不表示试验已经完成”拆开，第二块把“已经完成”误当独立事实，最终回答错误地声称材料矛盾。

非原料页的归纳现在优先在块末700字符内寻找中文句末或换行；没有可用边界时仍有界硬切，但每块携带前后各最多120字符的只读相邻原文，明确仅用于否定/指代消歧，不计入本块覆盖，也不单独归纳。覆盖范围仍连续、无重叠、无遗漏，实际分块数量参与32块限制；相邻原文同样计入最终请求预算。全页修订的输出拼接契约未改，既有source-reading缓存未重建。

两项新增回归分别覆盖有标点的否定句与无标点的硬切，验证最后一条user原文拼回恰好等于整页、块大小有界、相邻片段含完整否定上下文；页面任务定向13项通过。真实复验保留历史失败，不以标记覆盖断言独自证明语义正确。

## Alternatives considered

- 只增加提示词而保留固定硬切：模型仍可能看到缺少否定词的半句；同时调整边界并提供有界相邻原文。
- 重叠正文并把每块都当独立完整来源：重复计入覆盖且会重复归纳；相邻原文单独标注，不加入覆盖范围。
- 仅通过菜单填入提示词：未建立任务或版本身份，不能作为边界。
- 始终发送全文：短问题浪费预算，超限时也不能表达缺少哪部分覆盖。
- 重新实现来源阅读缓存：与后台管线产生双重版本及覆盖真源，不采用。
- 草拟时临时获取最新 basis：无法证明用户批准的是显示时版本，不采用。

## Verification

局部问题不携带无关全文；全文任务不得伪装覆盖；选区编辑不动其他段落；来源或人工内容变化拒绝旧草稿。两入口的最终引用验证保留。真实模型全文覆盖与指令遵从独立验收。

## Consequences

长非来源页完整修订按连续片段编号组装，超过32段或任一片段失败时不创建部分草稿；代价是额外模型请求及段间衔接的人工复核。页面选区必须按 Unicode 字符而不是 UTF-16 code unit 传递。
