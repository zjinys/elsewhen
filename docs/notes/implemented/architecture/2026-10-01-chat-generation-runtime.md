# Agent Note: 统一聊天生成运行与恢复边界

Status: implemented

## Problem

旧同步回复缺少稳定 run 身份、输入截止点、过程记录和统一终态。生成期间到来的新消息可能被“读最新用户消息”的辅助函数取到；以删除已提交事件处理 failover 会破坏本地事实和恢复依据。

任务归属：[AI 对话 Roadmap C02–C04](../../../roadmap/2026-09-30-ai-chat-experience-roadmap.md)。本 Note 细化[共享契约](../../../testing/ai-chat-contract-and-baseline.md)。C02 运行底座已交付；本文不把已有流式工程能力等同于 C03/C04 的全部性能和真实模型验收。

## Decision

- schema v11 以 SQLite 保存 run、输入身份、历史基底 hash、owner/租约、单调事件序号、请求元信息、工具结果和最终回复关联。同会话串行，终态不可复活。
- worker 使用自己的 Store/连接和固定输入截止点。memory、FollowUp、写意图、原始事件关联及生成材料的指令归属统一使用该快照；创建后、worker 启动前的历史变化拒绝执行。来源和页面版本仍在业务确认边界核验。
- 同步 `generate_reply` 和 start/observe/stop 门面调用同一核心。Provider 配置在准备阶段固定，脱敏身份进入运行事件，密钥不进入常规诊断。
- 事件序号与写入在同一事务提交。最终答案在引用/保存声明核验后与 assistant 消息和运行终态一起提交。保存成功的事件不会因 Provider 故障删除，重试通过固定输入关联复用事件及分析任务。
- 已执行操作、待审提议、正文草稿和最终回答分别持久化。目录提议暂存和生成材料写入在事务内检查运行 owner/取消；缺少 tool_result 的步骤在结束或租约恢复时明确记录为 uncertain，不自动重放。
- C01 审批执行租约与模型生成租约互相独立。停止生成不撤销已接受动作，也不停止后台分析/digest。

## Preview and transport

OpenAI-compatible SSE 按字节组帧，完整事件才解 UTF-8/JSON。工具参数完整且为 JSON object 才返回编排层。仅消费 choice 0，私有 reasoning 字段不产生正文事件。同一次请求累计 usage 覆盖而非逐 chunk 相加；无 usage 保持未知。

HTTP 等待响应头和停滞 body 都通过 25ms 本地检查点取消。显式 stream 不支持才降级；显式 native tools 拒绝保留旧文本协议兼容，鉴权/超时/损坏流不假装是工具协议不支持。Ollama 原生路径保留非流式响应，但 HTTP 可以取消。

预览采用保守句边界缓冲：协议/代码/引用起始符、写入声明或动作承诺之后的内容等待最终核验。不完整句以及超过 4096 字节的单句不提前放行。可预览句按 100ms / 2KiB 写检查点；这是词法屏障，不是任意语言的语义证明，最终校验仍不可省略。

Flutter 两个入口共享 controller：每 300ms 最多读取 64 个事件，不重叠轮询；快照恢复处理错会话、错 run、重复、序号缺口和漏收终态。最近工具状态上限 20 项。预览以无链接的“未核验草稿”显示，最终快照刷新已持久化消息。失败重试绑定原输入 ID，启动结果不确定时保留原幂等键；切页仅解除观察，不取消生成。

## Shutdown and recovery

正常桌面“退出”仅停止本进程注册的运行并最多等待 500ms，UI 等待上限 750ms；关闭到托盘继续运行。owner 可在有效租约内 flush 取消之前已检查的预览字节，不能启动新业务动作，终态拒绝迟到 flush。

异常退出可能丢失未落盘批次和仍在等待校验的句段。启动/查询恢复过期租约，不因本进程注册表为空而抢占另一进程健康运行。不能承诺恢复隐藏推理、服务商计算/计费立即结束或 token 精确续接。

## Validation

- C02/C03 集成门禁：全量 Rust 398 passed / 3 ignored / 0 failed；全量 Flutter 251 passed；release 构建和 FRB 重生成通过。
- Flutter 全量 analyze 无编译错误，仍有 4 条既有 warning 和既有 infos，退出码 1；共享 controller/status 和两个聊天入口的定向检查无问题。
- Rust 覆盖输入快照、历史基底冲突、幂等启动、事件分页、取消/完成竞争、终态 fencing、过期恢复、未知工具结果、检查点 flush、删除与事件任务去重。loopback 测试覆盖 UTF-8/工具 JSON 分片、累计 usage、断流、静默响应头/body 取消和保存声明预览隔离。
- 隔离真实 Bridge 覆盖主对话/知识页 SSE 工具往返、重复启动、分页恢复、错会话拒绝与取消；全部使用临时库和合成材料。Flutter 假服务关闭 HttpResponse 输出缓冲后才模拟中途可见数据，不人为拆最终回答伪装流式。
- 后续 C05 追加了预算配对和预选材回归，测试结果与限制继续记在 Roadmap，不能将本条历史门禁计为后续全部改动已验收。

## Alternatives considered

- **只在 Dart 保存 generating Set：** 无法覆盖重启、另一入口和迟到回包，不作为运行权威。
- **全局共享单 Store：** rusqlite 连接不直接作为 Sync 实例共享；worker 自有连接隔离事务，注册表只管理本进程停止范围。
- **每个 chunk 全量 upsert：** 会随回复长度放大写入；采用有界增量检查点和权威终态快照。
- **立即展示所有模型正文：** 会泄露跨 chunk 工具协议、未校验引用与保存声明；宁可等待句边界或最终核验。
- **失败后删除事件再重试：** 不采用；输入关联和业务回执承担幂等。
- **生成终态自动执行待审提议：** 不采用；生成、审阅与执行是不同状态机。

## Consequences

运行可以跨切页恢复，失败和取消不会伪装为回滚，工具与原始输入有稳定身份。代价是本地运行事件需要存储空间，保守预览会延迟部分句子，轮询有明确的 300ms 节奏；长历史的原始快照读取成本仍由 C05/C06 优化，不据此宣称大规模性能完成。

真实模型时间感知、全文覆盖、指令遵从及第一阶段端点人工验收尚未由这组工程测试证明。C03 性能实测和 C04 用户可理解的结果/证据展示仍按子路线分别闭环。
