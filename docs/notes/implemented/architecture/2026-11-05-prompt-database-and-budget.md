# Agent Note: 本机 Prompt 修订管理与固定指令预算

Status: implemented

## Problem

Prompt 分散于代码常量，修改需要重编译，且旧缓存没有绑定具体指令版本。预算路线中旧基础指令体积与增量下发目标尚未收口。

## Decision

2026-11-08 展示调整：设置中的“加载提示词”和“查看运行版本”默认隐藏。连续点击“提示词”标题10次后，仅在本次设置页面显示；未解锁前两次点击间隔超过2秒重新计数，离开页面后重置。解锁不加载模板、不发模型请求、不修改偏好或激活修订，原有按钮动作保持不变。提示词/真实Bridge编辑专项及设置标题点击/超时重置/语言切换3项通过（`/tmp/prompt-hidden-test.log`），修改入口analyze无问题。

迁移 73 创建设计中的七张核心表，并增加本机阅读任务绑定表。默认文本位于 resources/prompts，编译嵌入二进制。注册 key 才能产生行为；角色/风格、摘要/阅读/分析/消化方法可编辑，执行和输出协议只读。数据库修订不可变，保存仅产生草稿；按 key/locale 的 CAS 激活或恢复默认，旧内置修订可回滚。列表和历史 API 有分页上限。

主对话执行前保存 bundle，并关联 chat_runs 和每次 chat_run_requests；同一运行的工具循环、摘要和 failover 使用固定版本。设置修改只影响后续运行。后台分析、消化以任务身份固定；全文阅读按来源快照与契约版本建立持久绑定，跨 tick/重启使用相同 bundle。只查看页面或队列不建立任务。新 owner 不持有本机绑定，重新建立任务，不声称延续远端自定义版本。

摘要节点 basis 包含摘要 policy/contract 的依赖 hash，编辑聊天风格不会改变摘要依赖。阅读按任务固定的策略指纹隔离节点，队列和编译读面使用同一策略。旧产物保留，读取新来源时按正常有界调度处理。旧 PageMark 仍保留可读原摘要。

中文首版交付时运行/数据集默认均为zh-Hans。2026-11-06后续[多语言路线](../../../roadmap/2026-11-06-multilingual-support-roadmap.md)已接通UI切换、双语模板/独立激活与运行语言快照，详见[实现记录](2026-11-06-multilingual-runtime.md)；知识产出语言修改仍待L5同步，不能据此前期工程宣称完整国际化。自定义模板、激活与bundle继续是本机配置/证据，不同步。

设置 → 模型 → 提示词提供按需加载、正文编辑/默认预览、保存草稿、显式启用、历史回滚、恢复默认、近期运行版本与文本查看。页面本身不触发模型请求；预览 token 为本地估算。

固定默认指令精简为角色/风格 + 只读协议；常驻指南压缩并保持按工具注入。测试实测 deepseek-flash 口径 BASE 1767 + guides 165 + 消息开销16 = 1948 token，断言完整默认固定指令 <3000。动态上下文和工具 schema 继续独立预算，自定义正文允许更长但仍受整体请求预算约束。

## Alternatives considered

不采用“只发本轮变更段”的线协议：现有 OpenAI 兼容请求是独立完整 messages，不依赖服务端保存前轮指令。只删重复内容会丢失约束。保留稳定前缀与完整请求；未来支持有状态 API 时另立能力协商。数据库化本身不减少 token。

不允许自由修改固定 JSON/文本工具协议，不以编辑 Prompt 授予工具执行权限。不做跨设备自定义模板同步。多语言后续进度统一归属独立路线；这里不维护另一份实施清单。

## Consequences

修改角色与方法不必重编译，历史运行可查实际版本，版本切换不会在正在构建的阅读树中混入新指令。代价是本机修订与运行证据持续占空间，目前无删除入口。首版仅注册主对话与摘要/阅读/分析/消化的核心指令；临时内容预览、其他业务内动态提示仍保持代码控制，不冒充全仓字符串全部入库。

验证：`cargo test --all-targets -- --test-threads=4` 库1063 passed / 20 ignored、集成2 passed，0 failed；Prompt存储专项4项、知识专项70 passed / 2 ignored；Flutter全量535 passed，新增真实桥接与按需加载专项2项通过。修改界面/桥接入口/测试 analyze 无问题；桥接再生成与release库编译通过。默认固定指令实测1948 token。日志位于 /tmp/prompt-all-final.log、/tmp/prompt-flutter-final.log、/tmp/prompt-bridge-tests.log。真人模型质量与 GUI 体验仍需实机验收。
