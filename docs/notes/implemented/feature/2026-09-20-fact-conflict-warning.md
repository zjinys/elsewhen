# Agent Note: 派生事实冲突提示

Status: implemented

## Problem

同一知识页可能由多个事件产生同一主题但不同取值的派生事实。此前页面只平铺显示，用户无法快速知道需要人工判断。

## Decision

知识页按全角冒号前的事实主题分组；同一主题出现不同完整事实文本时标记为可能冲突。页面显示警告，并继续保留每条来源事实。用户通过现有的“移除这条事实”操作删除错误派生事实，原始事件和来源记录保持不变。

## Alternatives considered

- 在写入时覆盖旧事实：会丢失历史证据，因此不采用。
- 依赖模型判断冲突：结果不可预测且无法保证来源一致，因此先采用确定性的页面提示。

## Consequences

用户可以在知识页直接发现并处理冲突，且不会破坏原始事件。当前冲突识别针对结构化事实文本的主题前缀；更复杂的事实语义合并和实体合并仍属于后续 Phase 4B 工作。
