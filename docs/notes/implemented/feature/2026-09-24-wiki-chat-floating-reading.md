# Agent Note: 知识页浮动 AI 对话与回复阅读

Status: implemented

## Problem

固定宽度的页内对话侧栏压缩知识页正文，长回复需要在狭窄区域内反复滚动；AI Markdown 被当作原文显示。窄窗口另用底部弹窗，交互不一致。

## Decision

知识页右下角提供 AI 对话入口，点击后在当前页上展开有界浮层。浮层可从头部拖动、缩小成入口图标，缩小后保持已有会话组件状态；仅首次展开时初始化页内会话，避免只浏览页面就创建空会话。浮层尺寸随视口收缩并限制拖动范围。

AI 回复复用现有 `MarkdownView`，用户消息仍按原文显示。双击 AI 回复打开更宽的独立阅读窗口，带滚动与文本选择；原聊天仍保留在浮层中。

## Alternatives considered

- 保留固定侧栏、仅加宽：继续占用正文空间，窄屏仍需另一套交互。
- 将整个聊天放入模态窗口：会阻断边看知识页边提问，也无法拖动调整位置。
- 每次缩小时卸载聊天：会丢失输入及滚动状态，并在再次展开时重载消息。

## Consequences

正文不再被聊天栏挤窄，长回复可独立阅读；悬浮窗口可能覆盖正文，用户可拖动或缩小。Markdown 渲染沿用仓库已有语法支持范围。
