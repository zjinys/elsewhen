# Agent Note: 目标树导航与白话行动档案

Status: implemented

## Problem

目标左栏同时展示计划看板与目标清单，同一步骤重复出现，当前步/下一步和进度数字挤占导航空间。“抓手”“卡点”“认知切片”出现在界面和 AI 指令中，增加理解成本。

## Decision

目标左栏按计划分组：计划意图为父节点、符合当前状态过滤的步骤为子节点，支持展开/收起与点击选中；步骤只出现一次。不属于已加载计划的目标继续独立显示，加载失败明确提示。计划标题换行完整展示，步骤标题可换行；当前阶段用轻量状态文字标识，移除独立看板和进度计数。

目标详情保留与 AI 讨论并排，当前行动和困难完整展示，背景改为“为什么做”“怎样算完成”。创建、编辑、航向提醒、审阅和目标工具/上下文提示统一改用当前行动、困难、阶段。存储字段与工具协议不改名，确认制与状态机保持原实现。

## Alternatives considered

不继续保留两份清单再隐藏重复标题；统一导航树使每一步都能被选中。未引入新存储模型或修改计划推进逻辑。知识素材关联与个人画像仍由后续 Phase 2/3 负责，不在此次 UI 切片中提前宣称完成。

## Consequences

导航减少重复、主区保留全文。状态过滤会隐藏不匹配步骤，用户可开启暂停/完成过滤查看；尚未拥有计划读面的历史目标以独立项兜底。长标题采用换行，代价是单行高度不固定。真人 GUI 视觉验收待做。
