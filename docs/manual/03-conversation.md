# 对话 / Chatting with AI

对话是 Elsewhen 的主界面：问问题、让它记待办、整理想法，都在这里。The conversation view is the main screen: ask questions, have it add todos, organize ideas.

## 怎么聊 / How to Chat

在底部输入框打字，回车（或点发送按钮）发送。AI 会流式回复，边生成边显示。Type in the bottom box and press Enter (or tap send). AI replies in streaming — text appears as it's generated.

## 快捷输入 / Quick Input

输入框认识几种特殊写法。The input understands a few shortcuts:

| 输入 Type | 效果 What it does |
|---|---|
| `@人名` | 自动补全联系人 / autocomplete a contact |
| `#主题名` | 自动补全主题 / autocomplete a topic |
| 贴一个网址 | 进入收藏预览 / go to import preview |
| `进入主题：xxx` | 进入或新建一个主题 / enter or create a topic |

输入框左侧的 **⊕** 按钮还有「选择目录」和「查看输入格式」两个入口。The **⊕** button on the left offers "选择目录" (pick a folder) and "查看输入格式" (input help).

## 中途停止 / Stopping Mid-way

AI 回答时，点「停止生成」就能停。已经做完的事不会回滚。While AI is replying, tap 停止生成 to stop. Already-completed actions aren't undone.

## 一边等一边发 / Queuing

AI 还在回答时，你**可以继续发下一条**，它会排队按顺序处理。不用干等。While AI is replying, you **can keep sending** — messages queue up and are handled in order. No need to wait.

## AI 想动手时，会先问你 / AI Asks Before Doing

当 AI 想做「写」的操作（比如帮你记待办、保存一篇笔记、改名字），它**不会直接做**，而是先给你一张卡片：

- **接受**：真的去做；
- **拒绝**：什么都不做；
- **编辑**：改一改再决定。

右上角「审阅提议」会汇总当前会话里所有等你决定的卡片，可以一起看、批量处理。

When AI wants to *write* something (add a todo, save a note, rename), it shows a card first instead of acting directly:

- **接受** (accept): actually do it;
- **拒绝** (reject): do nothing;
- **编辑** (edit): tweak before deciding.

The 审阅提议 entry (top-right) collects all pending cards for this conversation so you can review them together.

## 追问 / Follow-up

AI 回答完，发个「？」或短句（如「继续」「为什么」）就能接着上一个话题聊。After a reply, a "？" or a short follow-up (like "继续", "为什么") continues the previous topic.
