# 收藏与导入 / Saving Content

把外部的网页、推文、文章存进知识库，随时回看、让 AI 帮你整理。Save web pages, tweets, and articles into the knowledge base to revisit or have AI process them.

## 收藏一个网址 / Save a URL

在知识库首页，或在对话输入框里，直接**粘贴网址**：

- **推文**（x.com / twitter.com）：抓取内容，先给你预览；
- **普通网页**：抓取正文，先给你预览。

预览页里你可以：先跟 AI 讨论这篇内容，或让 AI「整理为 Markdown」。**点「保存到知识库」才会真正存进去**，之前都不会动你的知识库。

Paste a URL in the knowledge-base home or the conversation input:

- A **tweet** (x.com / twitter.com) is fetched and previewed;
- A **web page** is fetched and previewed.

In the preview you can discuss it with AI or have it "整理为 Markdown". Nothing is saved until you tap **保存到知识库**.

## 粘贴文本 / Paste Text

知识库首页点「直接文本」，粘贴或输入内容，可选标题和标签，一键保存成新笔记。In the knowledge-base home, tap 直接文本, paste or type content, optionally add a title and tags, and save it as a new page.

## 导入一个项目目录 / Import a Folder

对话输入框的 ⊕ 菜单点「选择目录」（或输入「看看某个文件夹下的项目」），AI 会分析这个项目，提炼出方法、案例、规律。东西太少它会跳过，不会硬凑。Via the ⊕ menu's 选择目录 (or typing "看看某个文件夹下的项目"), AI analyzes a folder and distills methods, cases, and principles. If there's too little material, it skips rather than forcing it.

## 收藏之后 / After Saving

收藏的文章有状态：**待读 → 已读 → 值得使用 → 已采用 → 归档**，方便你知道哪些还没看、哪些用上了。Saved articles have a status: **待读 → 已读 → 值得使用 → 已采用 → 归档**, so you know what's unread and what you've actually used.
