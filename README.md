# elsewhen · 别时

> 本地优先的个人认知主循环 —— 记录此刻，复利此生。

**Elsewhen 是一个跑在你自己电脑上的个人认知系统**：以同时最多 3 个核心目标为航向，把随手记录、对话和网页剪藏沉淀为“关于你的持久知识”，让记录、知识和回顾始终对齐你真正想去的方向——而不是一堆一次性聊天记录。

```text
同时最多 3 个核心目标（航向）
随手记录 → AI 理解 → 人物 / 项目 / 认识沉淀 → 每日回顾 → 对照航向修正
保存内容 → 阅读理解 → 观点 / 灵感 / 创作素材 → 采用或归档
```

## 核心亮点

- **同时只追 3 个核心目标** —— 上限 3 条由系统硬保证；目标不是待办清单，带核心动力、当前抓手、已知卡点与完成判据；AI 日常零打扰，发现你偏离目标 3~5 天才以「事实 + 设问」递一面镜子
- **知识复利，不是聊天碎片** —— AI 把你的记录消化成持久知识页（成本 / 能力 / 资产 / 项目 / 关系 / 决策 / 习惯…），同一个事实被越多记录支持，页面越可信，向"更懂你"累积
- **原始记录不可变** —— 你的记录是你的日记，永不被 AI 覆盖；知识页全部是派生数据，可随时重新消化重建
- **AI 只提议，你做决定** —— AI 的整理、修订、新建建议走审阅卡，你点头才入库；你亲手编辑过的页面受保护
- **一切数据留在本机** —— 无云端账号、无遥测，离线可用；AI 只经你自己配置的接口访问；多设备间端到端加密同步，中继只中转密文，谁也读不到你的明文

## 它能做什么

- **随手记录**：主对话流直接说，或用快速捕获浮窗速记；AI 自动理解，不需要你整理格式
- **沉淀知识**：记录约 10 分钟后，AI 自动把值得留的内容消化成知识页；从网页、推文或一段文字导入的素材，原文锁存、AI 加工成观点和创作素材
- **共同推进目标**：目标页写下最多 3 个核心目标，AI 围绕你的抓手和卡点提供解题支持，帮你把大目标拆到本周可动的步骤
- **每日回顾**：按日/周/月回看记录与统计，AI 指出值得注意的偏差，不评判、不指路
- **多设备**（可选）：一端出示配对码、另一端扫码，新数据自动双向追平

## 快速上手

1. **配 AI**（设置 → AI Provider）：填接口地址 / API Key / 模型，保存即生效。未配置时记录照常保存，只是 AI 环节排队等待；
2. **随手记录**：主对话流直接说，或用快速捕获浮窗速记；
3. **定航向**（目标页）：写下最多 3 个正在推进的核心目标——为什么做、当前抓手、卡在哪、怎么算完成；
4. **知识库**：等 AI 自动消化，修订建议在审阅卡里逐条采纳；
5. **回顾**：每日回看记录与后续行动，对照航向看偏没偏。
